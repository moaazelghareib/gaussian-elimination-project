# 🧮 Gaussian Elimination Solver with OCR Support

A Python-based application designed to solve systems of linear equations using the **Gaussian Elimination** method, enhanced with Optical Character Recognition (**Tesseract OCR**) to extract equations directly from images.

---

## 📌 Project Overview
This project bridges core linear algebra mathematics with practical software engineering. Instead of manually inputting matrices, the system can process image inputs containing linear equations, extract the numerical values using Tesseract OCR, and apply the Gaussian Elimination algorithm to compute the exact solution.

---

## 🛠️ Tech Stack & Tools
* **Python** (Programming Language)
* **Tesseract OCR** (Optical Character Recognition for image-to-text)
* **NumPy / Standard Python Lists** (Matrix Operations & Data Structures)
* **Linux Packages (`packages.txt`)**: Tesseract OCR engine integration.

---
